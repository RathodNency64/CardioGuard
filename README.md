CardioGuard is an educational web application for demonstrating a cardiovascular disease classification model. It uses the exact 11-feature input vector from the supplied notebook and calls a tuned Random Forest artifact saved from that notebook's GridSearchCV configuration.

> This application is developed for educational and research purposes only. It is not a medical diagnosis or a substitute for professional medical advice.

## What is included

- React + Vite frontend with responsive pages for overview, prediction, how it works, model details, and verified project insights.
- Flask + Flask-CORS backend with `/api/healthz`, `/api/predict`, `/api/model`, and `/api/insights`.
- `backend/model/cardio_model1.pkl`, generated with the notebook's exact classification feature order and tuning grid.
- The supplied dataset and notebook in `backend/model/` and `eda/`.
- Vercel-friendly frontend build and Render configuration in `render.yaml`.

## Model contract

The classifier expects these features in this exact order:

```text
age, gender, height, weight, ap_hi, ap_lo,
cholesterol, gluc, smoke, alco, active
```

The source dataset stores `age` in days. CardioGuard accepts age in years in the form and converts it to days before calling the model. The other values use the source notebook's encodings:

- `gender`: `1` or `2`
- `cholesterol`: `1` normal, `2` above normal, `3` well above normal
- `gluc`: `1` normal, `2` above normal, `3` well above normal
- `smoke`, `alco`, `active`: `0` or `1`

## Run locally

Open a terminal in the project root.

### 1. Start the Flask backend

```bash
python -m venv .venv
```

Windows:

```powershell
.venv\Scripts\activate
```

macOS/Linux:

```bash
source .venv/bin/activate
```

Install backend dependencies and start the API:

```bash
pip install -r artifacts/cardioguard/backend/requirements.txt
python artifacts/cardioguard/backend/app.py
```

The API runs at `http://localhost:5000`.

Check it:

```bash
curl http://localhost:5000/api/healthz
```

Expected response:

```json
{"status":"ok"}
```

### 2. Start the frontend

In a second terminal:

```bash
cd artifacts/cardioguard
pnpm install
cp .env.example .env
pnpm run dev
```

Open the Vite URL shown in the terminal, usually `http://localhost:5173`.

The frontend uses `/api` by default, which works with the Replit preview proxy. For a separate local Flask process, create `artifacts/cardioguard/.env` with:

```bash
VITE_API_URL=http://localhost:5000/api
```

### Test a prediction directly

```bash
curl -X POST http://localhost:5000/api/predict \
  -H "Content-Type: application/json" \
  -d '{"age":55,"gender":2,"height":170,"weight":75,"ap_hi":130,"ap_lo":80,"cholesterol":1,"gluc":1,"smoke":0,"alco":0,"active":1}'
```

The response is generated by the real serialized model and includes `prediction`, `prediction_label`, `probability`, and `model_name`.

## Deploy the backend to Render

1. Push the project to GitHub. Keep `artifacts/cardioguard/backend/model/cardio_model1.pkl` in the repository; it is required at runtime.
2. In Render, create a new **Web Service** from the repository.
3. Set the service root directory to `artifacts/cardioguard`.
4. Render reads `render.yaml`; the backend root is `backend`.
5. Set `CORS_ORIGINS` to the final Vercel frontend URL, such as `https://your-app.vercel.app`.
6. Deploy and copy the Render URL, for example `https://cardioguard-api.onrender.com`.
7. Check `https://YOUR-RENDER-URL/api/healthz` before connecting the frontend.

If Render asks for manual settings instead of using `render.yaml`:

- Build command: `pip install -r backend/requirements.txt`
- Start command: `gunicorn --chdir backend app:app`
- Health check path: `/api/healthz`

## Deploy the frontend to Vercel

1. Import the GitHub repository into Vercel.
2. Set the project root directory to `artifacts/cardioguard`.
3. Framework preset: **Vite**.
4. Build command: `pnpm run build` (Vercel supplies the build environment; if needed use `PORT=5173 BASE_PATH=/ pnpm run build`).
5. Output directory: `dist/public`.
6. Add this environment variable:

```text
VITE_API_URL=https://YOUR-RENDER-URL/api
```

7. Deploy. Visit the Vercel URL and submit the prediction form.
